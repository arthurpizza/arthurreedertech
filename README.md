# ARTHUR REEDER TECH

This is my business end — the source for [arthurreeder.tech](https://arthurreeder.tech).

Built with [Hugo](https://gohugo.io) using the custom `art` theme in `themes/art` (plain CSS, no build step, no JavaScript). Deployed by Netlify; `netlify.toml` pins the Hugo version.

Run it locally:

```bash
hugo server
```

Then open http://localhost:1313.
